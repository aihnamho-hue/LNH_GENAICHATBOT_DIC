③ ★ 홈 단추가 왜 안 지워졌었나
───────────────────────────────────────────────────────────

  v152 에서 넷에 `hidden` 을 붙였는데 화면에는 그대로 있었습니다.

     .home-top .home-ico { display: inline-flex; }   ← 이 한 줄이
     [hidden] { display: none; }                     ← 이것을 이겼습니다

  `hidden` 은 브라우저 기본 규칙이라, 우리가 쓴 한 줄보다 약합니다.
  붙여 놓고 안 보이는 줄 알았습니다.

  검사도 못 잡았습니다. 「숨겼다고 적혀 있는가」만 보고
  「보이지 않는가」를 안 봤습니다. 게다가 검사 도구(jsdom)는
  이 어긋남을 원리상 못 잡습니다 — 고치기 전 파일로 돌려서 확인했습니다.

  그래서 이번에는 넷을 ★ 아예 그 줄 밖으로 내보냈습니다.
  안 보이는 게 아니라 없습니다. 검사도 마크업을 직접 셉니다.

  덤으로  [hidden] { display: none !important; }  한 줄을 맨 위에 뒀습니다.
  이번 판에서 반 번호 칸도 hidden 으로 감췄는데,
  이 줄이 없었으면 그것도 그대로 보였을 겁니다.


④ ★ 동의 기록을 어떻게 받으시나
───────────────────────────────────────────────────────────

  학습자가 동의하고 소속을 고른 그 순간, 드라이브에 한 장이 쌓입니다.

     호아랑동의_KIIP_바트_20260830_170512.txt

     ┌────────────────────────────────────────┐
     │ 호아랑 — 녹음·연구 자료 수집 동의 기록  │
     │ ====================================== │
     │ 동의한 사람 : 바트                      │
     │ 소속        : KIIP 사회통합프로그램     │
     │ 동의한 때   : 2026년 08월 30일 17:05    │
     │ 문안 판본   : 1.0                       │
     │ 이름표 판본 : 2                         │
     │ 화면 언어   : mn                        │
     └────────────────────────────────────────┘

  · 드라이브에서 「호아랑동의」로 검색하면 명단이 나옵니다
  · 이름으로 정렬하면 기관별로 모입니다 (대화 자료와 같은 축)
  · 사람당 한 장. 다시 동의를 받거나 소속을 바꾸면 한 장 더
  · ★ 대화를 안 한 학습자도 남습니다 (지금까지는 안 남았습니다)

  왜 PDF 가 아닌가 —
  18개 언어 글꼴을 서버에 실을 까닭이 없습니다.
  이건 선생님이 폴더에서 훑을 목록이지 배포할 서류가 아닙니다.
  학습자가 제 동의서를 종이로 받고 싶으면
  설정 → 「동의서 받기」 → 인쇄 → PDF로 저장 하면 됩니다. (그대로입니다)
