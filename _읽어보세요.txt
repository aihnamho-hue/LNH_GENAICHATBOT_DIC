  호아랑 v164  (2026-10-01)
  ★ 학습자 말을 받아쓸 때 「한국어」라고 알려 줍니다
═══════════════════════════════════════════════════════════


★ 사후평가(10월 3일) 전에 — 오늘이나 내일 오전에 올리고, 바로 한 번 시험해 보세요.
───────────────────────────────────────────────────────────

  무엇이 바뀌나

    호아랑의 대답은 그대로입니다(원래부터 소리를 직접 듣고 알아들었습니다).
    바뀌는 것은 **말풍선에 찍히는 학습자의 글자**입니다.

    지금까지는 받아쓰기가 「어느 나라 말인지」부터 스스로 추측했습니다.
    억양이 강한 한국어를 다른 말로 잘못 짚으면 글자가 엉망이 되었고,
    그 글자로 판정·개입·총평이 정해졌습니다.
    이제 「이 소리는 한국어다」라고 알려 줍니다.

    간투사(음… 어…), 되풀이, 「아 아니, ~요」 같은 자기 수정은 그대로 남습니다.
    학습자의 문법 오류도 고치지 않고 들린 대로 적습니다.


① 올리는 법 — 지난번과 같습니다
───────────────────────────────────────────────────────────

  1. github.com → [Add file] → [Upload files]
  2. ★ 폴더째 끌지 말고, 폴더를 열어 Ctrl+A 로 전부 골라 끌어 놓는다
  3. 커밋 메시지에 v164
  4. 3~5분 기다린다


② 올린 뒤 꼭 확인 — korean-dic.onrender.com/version
───────────────────────────────────────────────────────────

      "server": "v164"    "screen": "v164"    "match": true

  그리고 "stt" 안의 "lang" 을 봅니다.

      "want": "ko-KR"     "active": true      "sdk": true

  ★ 자유 대화를 한 번 해 보고(아무 말이나 서너 번) 다시 열어 보세요.

      "seen": {"ko": 12}      ← ko 만 오르면 정상입니다


③ 혹시 문제가 생기면 — 두 단계
───────────────────────────────────────────────────────────

  ■ "active": false 이고 "fail" 에 글이 차 있다

      Gemini 가 이 설정을 거부한 것입니다. 걱정 없습니다 —
      호아랑이 스스로 설정을 빼고 다시 연결했으므로 대화는 v163 과 똑같이 됩니다.
      그대로 두셔도 됩니다.

  ■ 대화가 안 열리거나 이상하다  →  끄는 스위치

      Render → 호아랑 서비스 → Environment → Add Environment Variable
          Key   : STT_LANG
          Value : off
      [Save] 를 누르면 서버가 저절로 다시 켜지고, v163 과 똑같이 돕니다.
      (코드를 다시 올릴 필요 없습니다)

  ■ 그래도 이상하다  →  v163 으로 되돌리기

      프로젝트 폴더의 「되돌리기_v163」 안의 파일을 깃헙에 올리면 됩니다.
          main.py · app.html · app.html.gz · static/sw.js
